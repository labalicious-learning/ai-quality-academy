# Academy project instructions

This repository is a teaching package. All sample data is fictional.
Core commands: npm start (loopback lab), npm test (fixture correctness), npm run verify (course links).
The buggy candidate is deliberately incorrect. Change it only for an explicitly requested learner exercise; preserve the fixed comparison and the requirements.
Never change requirements to make a test pass. Fixture tests verify intended defects, not release readiness.
For blind student exercises, restrict model context to sandbox/, fixtures/allocation-requirements.md and the assigned handout. Instructor answer keys and expected evaluation labels are not allowed task context until debrief.
No real cloud, email, database or identity credentials are required.
